# 常见问题

## 保存组件后为什么没有生效？

功能插件：确认「设置 → 扩展」中已启用；列组件 / 画布组件：确认「设置 → 周报组件」中已启用。如果仍不生效，点击「设置 → 扩展」里的热加载或重新加载应用，并查看列表中的错误信息。

## 组件里的样式不跟随主题？

不要写死颜色。使用 `var(--el-bg-color)`、`var(--el-text-color-primary)` 等 Element Plus 变量，并避免在组件根节点上设置不透明背景。

## 可以 import npm 包吗？

只支持文档中列出的运行时模块。其他依赖请先放到 `resources/js` 并以全局变量形式使用，或改成资源目录内的 ES Module。

## 插件脚本的执行顺序？

按文件名排序串行加载。需要明确顺序时使用数字前缀，例如 `01-init.js`、`02-search.js`。

## 修改资源后需要重新构建客户端吗？

不需要。外部组件保存后热加载；插件脚本和样式重新加载应用即可生效。只有修改客户端本身的 Vue 源码才需要重新构建。

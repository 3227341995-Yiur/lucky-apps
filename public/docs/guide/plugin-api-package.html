插件 API 包 ​

外部组件项目不再直接访问 ctx.weekReport 或全局变量，统一从 npm 包导入：

bash
pnpm add @week-report/plugin-api
js
import { definePlugin, components } from '@week-report/plugin-api'
import KpiCard from './KpiCard.vue'

export default definePlugin({
  name: 'kpi-card',
  apply() {
    components.registerCanvas('KpiCard', KpiCard, {
      value: 'kpi-card',
      icon: 'TrendCharts',
      description: 'KPI 指标卡'
    })
  }
})

导出 ​

导出说明
definePlugin(plugin)声明 Cordis 插件对象
components.registerColumn注册表格列组件
components.registerCanvas注册画布组件
components.registerColumnSlot注册列属性编辑插槽
components.list / listColumns / listCanvas / has查询已注册组件
navigation.register注册左侧栏入口和自定义页面
settings.register注册设置中心面板
branding.get / set / onChange读取或修改程序名称、图标（只影响界面；窗口标题与 exe 图标走设置中心「程序名称与图标」，保存后同步窗口/托盘/exe 文件图标）
events.on / once / off订阅宿主事件
ui.toast / selectReport / openSettings / openImportExport / openDesigner / openTemplates调用宿主界面
commands.register / run / list注册/执行命令
useWeekReport()返回完整宿主 API

宿主加载 client bundle 前会设置 __WEEK_REPORT_HOST__，API 在 apply() 内或之后调用都有效。

侧边栏页面与设置面板 ​

js
import { definePlugin, navigation, settings } from '@week-report/plugin-api'
import TrashPage from './TrashPage.vue'

export default definePlugin({
  name: 'trash-bin',
  apply() {
    navigation.register({
      id: 'trash-bin',
      label: '回收站',
      icon: 'Delete',
      component: TrashPage
    })
  }
})

设置面板同理使用 settings.register({ id, label, icon, component })。

导航项支持 icon（Element Plus 图标名）、iconSvg（HTML 字符串）或 iconComponent（Vue 组件）。组件图标可以自己处理状态和徽标，例如回收站入口：

js
import TrashNavIcon from './TrashNavIcon.vue'

navigation.register({
  id: 'trash-bin',
  label: '回收站',
  iconComponent: TrashNavIcon,
  component: TrashPage
})

包结构 ​

text
packages/plugin-api/
├─ package.json
├─ index.d.ts
├─ src/index.js
└─ README.md

组件包在 package.json 中声明依赖：

json
{
  "dependencies": {
    "@week-report/plugin-api": "workspace:*"
  }
}

发布到公司 npm registry 后，外部项目直接安装即可，不需要复制宿主源码。

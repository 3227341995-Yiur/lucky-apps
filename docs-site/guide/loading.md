# 启动加载动画

应用启动时先显示加载动画，等前端资源和 Cordis 客户端 bundle 就绪后再进入界面。
配置保存在浏览器 `localStorage` 的 `wr:loading`，启动时同步读取，不依赖数据库。

## 配置入口

设置中心 → 加载动画。修改后立即保存；点击「预览动画」可以当场播放一遍。
正式启动动画在下次打开应用时生效。

## 可配置项

| 配置 | 说明 |
| --- | --- |
| 加载文字 | 逐字绘制的文字，默认 `loading`，最多 40 个字符 |
| 副标题 | 文字下方的小字，例如「正在加载资源」 |
| 字体 | 手写体 / 衬线体 / 等宽体 / 无衬线体 |
| 字号 | 28–160 |
| 文字颜色 / 背景颜色 | 描边、笔尖、副标题和背景颜色 |
| 收尾效果 | `爆炸粒子` / `上升消散` / `火花飞散` |
| 预设 | 经典蓝 / 霓虹 / 糖果 / 暗夜 |
| 粒子数量 / 字 | 0–40，0 表示不生成粒子 |
| 粒子形状 | 混合 / 圆点 / 方块 / 星形 |
| 速度 | 0.4–2.5 倍速 |
| 显示笔尖 | 是否显示跟随绘制位置的笔尖 |
| 粒子颜色 | 逗号分隔的颜色列表 |

```js
// localStorage['wr:loading']
{
  text: 'loading',
  subtitle: '正在加载资源',
  font: '"Segoe Script", "Bradley Hand", cursive',
  fontSize: 72,
  color: '#3574f0',
  background: '',
  effect: 'explode',
  particleCount: 36,
  particleShape: 'mixed',
  particleColors: '#3574f0,#36a3ff,#67c23a,#e6a23c,#f56c6c,#8b5cf6',
  showPen: true,
  speed: 1
}
```

## 动画实现

- 经典版：SVG `<text>` 按字符裁剪逐字绘制，使用手写字体和笔尖跟随。
- 每个字符完成后填充，笔尖跟随字符前进。
- 收尾时按字符生成粒子；效果受上面的配置控制。
- 任意配置错误会回退到默认值，不会阻塞启动。

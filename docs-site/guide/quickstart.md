# 快速开始

先拿到扩展资源目录，然后按下面的结构放入文件。目录不存在时可直接新建。

## 扩展资源目录

```text
src-tauri/resources/
├─ css/
│  └─ theme.css
├─ js/
│  └─ my-plugin.js
└─ comps/
   ├─ HelloCell.vue
   └─ HelloCell.cslot.vue
```

可以在「设置 → 扩展」中复制资源路径、重新扫描或热加载组件。

## 三步开始

1. **放文件**：组件放 `comps`，插件脚本放 `js`，全局样式放 `css`。
2. **保存**：组件保存后自动热加载；插件脚本和样式在重新加载应用后生效。
3. **启用**：到「设置 → 扩展」确认资源已启用，出现错误会显示在列表中。

::: warning 加载顺序
插件脚本按文件名排序加载。需要强顺序时使用数字前缀，例如 `01-init.js`、`02-search.js`。
:::
